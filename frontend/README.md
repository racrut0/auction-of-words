# Фронтенд «Аукциона слов»

Запуск из папки `frontend`:

```powershell
npm.cmd ci
npm.cmd run dev
```

Проверка и сборка:

```powershell
npm.cmd test
npm.cmd run build
```

После входа доступны список лобби, подключение по коду, создание партии и комната ожидания. В настройках можно выбрать параметры партии и загрузить банк слов из текстового файла UTF-8. В файле нужны русские слова, разделённые пробелами, переносами строк, запятыми или точками с запятой. Повторы удаляются, Ё заменяется на Е. По умолчанию используется банк из 30 слов.

Интерфейс пока не подключён к серверному API. Лобби хранятся в `localStorage` этого браузера, пользователь и его идентификатор — в `sessionStorage` вкладки. Для проверки нескольких участников можно открыть несколько вкладок одного браузера на одном адресе и войти под разными никами. Между устройствами данные не передаются.

Создание и изменение лобби вынесено в `src/services/lobbies.js`. Этот модуль нужно будет заменить при подключении сервера. Авторизация пока демонстрационная. Запуск партии не реализован.

Профиль открывается из верхнего меню или адресом `?page=profile` после входа. Статистика взята из `src/data/profile.js`: для аккаунта показан пример, для гостя — нулевые значения. Почта берётся из формы входа или регистрации; её изменение сохраняется в `sessionStorage` текущей вкладки. Запросы к серверу и отправка писем не выполняются.
