# Фронтенд «Аукциона слов»

Запуск из папки `frontend`:

```powershell
npm.cmd ci
npm.cmd run dev
```

Для входа, лобби и профиля запустите [бэкенд](../backend/README.md) на порту 8081. Vite перенаправляет запросы `/api` на `http://127.0.0.1:8081`. Если сервер запущен на другом адресе, задайте `API_PROXY_TARGET` перед запуском Vite. При размещении сборки направляйте `/api` на бэкенд с того же сайта.

Если локальный `backend/.env` создан из старого примера, приведите `CORS_ORIGINS` к формату списка JSON из нового примера или удалите эту строку для работы через Vite.

Проверка и сборка:

```powershell
npm.cmd test
npm.cmd run build
```

После входа доступны список лобби, подключение по коду, создание партии и комната ожидания. В настройках можно выбрать параметры партии и загрузить банк слов из текстового файла UTF-8. В файле нужны русские слова, разделённые пробелами, переносами строк, запятыми или точками с запятой. Повторы удаляются, Ё заменяется на Е. По умолчанию используется банк из 30 слов.

Лобби и участники хранятся в PostgreSQL. Сессия входа хранится в `sessionStorage` вкладки. Для проверки войдите как два разных игрока, создайте лобби, подключитесь по коду и подтвердите готовность обоих игроков. После старта делайте ставки на буквы, а после последнего лота выберите и отправьте слова из банка. Сервер покажет очки за раунд и итоговый счёт партии.

Для проверки с другого устройства в доверенной локальной сети можно запустить Vite командой `npm.cmd run dev -- --host 0.0.0.0` и открыть на втором устройстве адрес `http://<локальный IPv4 ПК>:5173`. Сам FastAPI остаётся доступен через прокси Vite.

Профиль открывается из верхнего меню или по адресу `?page=profile` после входа. Данные аккаунта и статистику возвращает сервер. Изменение почты сохраняется в базе. Для гостя профиль остаётся локальным. Подтверждение почты и восстановление пароля в интерфейсе пока недоступны.
