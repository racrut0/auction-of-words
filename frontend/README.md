# Фронтенд

Нужен Node.js. Запустите [бэкенд](../backend/README.md), затем откройте второе окно PowerShell в корне проекта.

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1
```

Откройте адрес из терминала. Обычно это [127.0.0.1:5173](http://127.0.0.1:5173/). Vite отправляет запросы `/api` на `http://127.0.0.1:8081`. Если у бэкенда другой адрес, задайте его в `$env:API_PROXY_TARGET` перед запуском Vite.

Для игры по локальной сети запустите `npm.cmd run dev -- --host 0.0.0.0`. На другом устройстве откройте адрес вашей сети из строки `Network` в терминале.

## Тесты и сборка

```powershell
npm.cmd test
npm.cmd run build
```

Сборка сохраняется в `dist`. При её размещении направьте запросы `/api` на бэкенд с того же адреса, с которого открывается игра.
