# Фронтенд «Аукциона слов»

Запуск из папки `frontend`:

```powershell
npm.cmd ci
npm.cmd run dev
```

Для регистрации, входа в аккаунт и профиля запустите [бэкенд](../backend/README.md) на порту 8081. Vite перенаправляет запросы `/api` на `http://127.0.0.1:8081`. Если сервер запущен на другом адресе, задайте `API_PROXY_TARGET` перед запуском Vite. При размещении сборки направляйте `/api` на бэкенд с того же сайта.

При запуске через Vite можно убрать строку `CORS_ORIGINS` из локального файла `backend/.env`, скопированного из примера.

Проверка и сборка:

```powershell
npm.cmd test
npm.cmd run build
```

После входа доступны список лобби, подключение по коду, создание партии и комната ожидания. В настройках можно выбрать параметры партии и загрузить банк слов из текстового файла UTF-8. В файле нужны русские слова, разделённые пробелами, переносами строк, запятыми или точками с запятой. Повторы удаляются, Ё заменяется на Е. По умолчанию используется банк из 30 слов.

Лобби хранятся в `localStorage` браузера, а сессия входа — в `sessionStorage` вкладки. Для проверки нескольких участников можно открыть несколько вкладок одного браузера на одном адресе и войти под разными никами. Между устройствами данные лобби не передаются.

Создание и изменение лобби вынесено в `src/services/lobbies.js`. Запуск партии пока недоступен.

Профиль открывается из верхнего меню или по адресу `?page=profile` после входа. Данные аккаунта и статистику возвращает сервер. Изменение почты сохраняется в базе. Для гостя профиль остаётся локальным. Подтверждение почты и восстановление пароля в интерфейсе пока недоступны.
