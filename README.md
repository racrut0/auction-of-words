# Аукцион слов

Браузерная игра для компании от 2 до 6 человек. Покупайте буквы на аукционе и собирайте из них слова, чтобы набрать больше очков, чем соперники.

## Как играть

1. Создатель лобби задаёт стартовый капитал, количество раундов, порядок игроков, штраф за букву и банк слов. Остальные входят по коду. Партия начинается, когда все готовы.
2. В каждом раунде буквы выставляются по очереди. По умолчанию в раунде 16 лотов, на каждый даётся 10 секунд. Игроки делают закрытые ставки. Букву получает тот, кто поставил больше, и только с него списываются монеты. При равных ставках действует порядок игроков.
3. После торгов игроки выбирают слова из общего банка. По умолчанию на это даётся 40 секунд. Каждую купленную букву можно использовать один раз за раунд. Отправить слова можно один раз.

Базовые очки за слово равны квадрату его длины. Например, «КОТ» даёт 9 очков. Если в этом раунде слово отправил только один игрок, его стоимость удваивается. Первый игрок, отправивший хотя бы одно слово, получает ещё 10 очков. За оставшиеся буквы из счёта вычитается штраф.

У каждого игрока свой баланс на всю партию. Остаток монет переносится между раундами, а в конце партии половина остатка прибавляется к сумме очков. Побеждает игрок с наибольшим итоговым счётом. При равном максимальном счёте победа общая.

## Запуск

1. Запустите [бэкенд](backend/README.md).
2. В другом окне PowerShell запустите [фронтенд](frontend/README.md).

Для проверки войдите как разные игроки в обычном окне браузера и в инкогнито. Создайте лобби, подключитесь по коду, подтвердите готовность и начните партию.
